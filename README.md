# Smart Weather App

A Flutter mobile application that provides real-time weather information using the Open-Meteo API. Users can search for weather by city name or use their current GPS location, save favorite cities, manage a personal profile, and receive local weather notifications.

## Features

- **City Weather Search** - Look up current weather conditions for any city worldwide.
- **Location-Based Weather** - Automatically fetch weather for your current GPS location.
- **Favorites Management** - Save frequently checked cities and quickly access them later.
- **Weather Details** - View temperature, humidity, wind speed, and atmospheric pressure.
- **Temperature Units** - Switch between Celsius and Fahrenheit in settings.
- **Local Notifications** - Enable notifications to receive weather updates when viewing a city.
- **User Profile** - Store and edit your name and email.
- **Persistent Settings** - Preferences and favorites are saved locally using SharedPreferences.
